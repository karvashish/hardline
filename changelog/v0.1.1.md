# v0.1.1 — 2026-05-10

Security and supply-chain hardening release. No behavioral changes for end users running existing profiles.

### Security

- All third-party GitHub Actions in CI and release workflows are pinned to commit SHAs (with `# v<n>` comments for Dependabot tracking), mitigating tag-rewrite supply-chain risk against `actions/checkout`, `actions/setup-go`, `actions/upload-artifact`, `actions/download-artifact`, and `softprops/action-gh-release`.
- `release.yml` workflow permissions tightened: `contents: write` is now scoped to the publish job only; build, test, and profile-package jobs run with `contents: read`.
- Workflow inputs (`github.event.inputs.tag`, `github.ref_name`) are passed through `env:` instead of inlined into shell `run:` blocks, eliminating a script-injection vector.
- Firewall diff renderer now bounds its LCS DP table input to 2000 lines per side, preventing a compromised remote from triggering a multi-GB allocation in the local Hardline process.
- Firewall rule normalization rejects rules with more than 65535 ports.

### Added

- CodeQL Go static-analysis workflow (`codeql.yml`) running on push to `main`, pull requests, and a weekly schedule.

### Tests

- Coverage uplift in `internals/apply` (87.4% → 92.0%) and `internals/plan` (89.0% → 93.1%) via direct unit tests for `formatShortDuration`, `countApplySteps`, `isDiffHeaderLine`, `normalizeReportFormat`, `dispositionCode`, `statusTitle`, `normalizedHighlights`, `previewPlanLines`, and `collectPlannedChanges`.
