# Built-In Plugins

Hardline ships with these built-in plugins. The package plugins are one per
package manager, because a profile is pinned to one target anyway and each
manager parses and pins packages its own way.

- [Packages Plugins](packages-plugin.md) — `packages_apt`, `packages_dnf4`, `packages_dnf5`
- [Template Plugin](template-plugin.md)
- [Service Plugin](service-plugin.md)
- [Firewall Plugin](firewall-plugin.md)
- [File Meta Plugin](file-meta-plugin.md)
- [Audit Plugin](audit-plugin.md)
- [SSH Plugin](ssh-plugin.md)

Use these pages as the configuration reference for step `config` blocks.
